# Pocket-Smart-AI - Your Smart Budget & Recommendation Assistant

Pocket-Smart-AI is an AI-powered budget planner that helps users manage expenses and gives smart saving recommendations using Google Gemini.

### Features
- Track daily expenses
- AI budget recommendations
- Smart saving tips using Gemini

### Tech Stack
- Google Gemini API, Python (app.py)

### How to Run
1. git clone https://github.com/rakshanasri1708-boop/Pocket-Smart-AI
2. pip install -r requirements.txt
3. Add Gemini API Key in app.py
4. python app.py
